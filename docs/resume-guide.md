> **목적**: 막차알리미(last-train) 프로젝트 성과를 이력서에 기재하기 위한 체계적 가이드

> **구성**: 3개 문서 + 단계별 진행표

## 📚 **생성된 3개 문서**

### 1️⃣ `resume-achievements-draft.md` (이 문서)
**내용**: 카테고리별 성과 항목의 초안→수정본 비교  
**목적**: 각 항목이 왜 그렇게 수정되었는지 이해  
**사용법**:
- 각 섹션의 "초안"과 "수정 후"를 비교
- "수정 이유" 표를 보며 표현 방식의 개선점 학습
- 모든 항목에 파일 경로 + 라인 번호 포함 (코드 검증 가능)

**구성**:
```
1️⃣ 데이터 모델링 / 상태 관리
2️⃣ REST API 개발 및 비즈니스 로직
3️⃣ 동시성/성능 처리
4️⃣ 인증/보안 구조
5️⃣ 예외 처리 및 테스트
6️⃣ 인프라/배포
```

---

### 2️⃣ `resume-verification-questions.md` (확인용)
**내용**: 이력서 기재 전 확인해야 할 5가지 기술 질문  
**목적**: 확실하지 않은 부분을 명확히 하기  
**사용법**:
- 각 질문의 "세부 확인 사항" 체크박스 확인
- "근거" 파일을 찾아서 코드 검증
- 회신 형식에 따라 답변

**핵심 5가지 질문**:
```
🔴 질문 1: Kakao OAuth2.0 구현 완성도
🟡 질문 2: FavoriteService 미커버 부분 (4%)
🔴 질문 3: TransitCacheWriter 구현 완성도
🟡 질문 4: 성능 측정 환경 (로컬 vs 프로덕션)
🔴 질문 5: Web Push 발송 구현 완성도
```

---

### 3️⃣ `resume-guide.md` (현재 문서)
**내용**: 진행 절차와 타임라인  
**목적**: 어떤 순서로 작업할지 안내
